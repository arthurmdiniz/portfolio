Atividade Prática — Meu Portfólio Web com IA + GitHub Pages
Desafio
Você foi desafiado a criar e publicar seu próprio site de portfólio profissional, utilizando Inteligência Artificial Generativa como copiloto de desenvolvimento.
O site deverá ser desenvolvido utilizando:
HTML para estruturar o conteúdo;
CSS para definir identidade visual, layout e responsividade;
JavaScript para implementar interatividade;
GitHub para armazenar e versionar o projeto;
GitHub Pages para publicar o site na internet.
Ao final, você deverá possuir um site real e público, acessível por meio de uma URL que poderá ser utilizada futuramente em seu currículo, LinkedIn ou apresentação profissional.

Objetivos de aprendizagem
Ao concluir a atividade, você deverá ser capaz de:
Aplicar conceitos básicos de HTML, CSS e JavaScript.
Utilizar IA generativa para apoiar o desenvolvimento de software.
Analisar e modificar código produzido por ferramentas de IA.
Identificar e corrigir problemas no código gerado.
Utilizar GitHub para hospedar um projeto de desenvolvimento web.
Publicar uma aplicação web utilizando GitHub Pages.
Avaliar criticamente os resultados produzidos pela IA.
Criar um produto digital autoral.
Taxonomia de Bloom
A atividade trabalha principalmente os níveis:
Aplicar → Analisar → Avaliar → Criar
O objetivo não é simplesmente copiar um código produzido pela IA, mas compreender, testar, modificar e publicar uma solução própria.

Requisitos mínimos do site
Seu site deverá possuir pelo menos quatro seções.
Sugestão:
1. Página inicial / apresentação
Apresente:
seu nome;
curso;
uma breve apresentação;
área de interesse;
objetivo profissional.

2. Sobre mim
Inclua informações como:
interesses;
habilidades;
tecnologias que está estudando;
objetivos acadêmicos ou profissionais.
3. Projetos ou tema escolhido
Apresente pelo menos três projetos, trabalhos, interesses ou conteúdos relacionados ao tema escolhido.
Cada item poderá conter:
título;
descrição;
imagem;
tecnologias utilizadas;
link;
botão para mais informações.
4. Contato
Inclua pelo menos algumas formas de contato profissional, por exemplo:
GitHub;
LinkedIn;
e-mail;
formulário visual de contato.
Não publique informações pessoais sensíveis, como endereço residencial, documentos, telefone pessoal ou outros dados que não gostaria de tornar públicos na internet.

Etapa 2 — Utilize a IA como copiloto
Você poderá utilizar ferramentas de IA generativa para auxiliar no desenvolvimento.
Exemplos:
ChatGPT;
GitHub Copilot;
Gemini;
Claude;
Microsoft Copilot;
outra ferramenta disponível.
A IA poderá ajudar você a:
criar a estrutura inicial;
sugerir HTML;
criar estilos CSS;
desenvolver funcionalidades JavaScript;
identificar erros;
melhorar a responsividade;
organizar o código;
sugerir melhorias.
Exemplo de prompt inicial
Você pode começar com algo semelhante a:
Crie um site de portfólio utilizando HTML, CSS e JavaScript.
O tema será [COLOQUE SEU TEMA].
Quero um design moderno e responsivo.
O site deve possuir uma seção inicial, sobre mim, projetos e contato.
Separe o código em index.html, style.css e script.js.
Explique brevemente o que cada parte do código faz.
Depois disso, continue conversando com a IA.
Não aceite obrigatoriamente a primeira versão.
Solicite melhorias.
Exemplos:
Torne o layout responsivo para celulares.
Explique esse trecho de JavaScript.
Por que esse código não está funcionando?
Melhore a organização visual dos cards.
Adicione um botão para alternar entre modo claro e escuro.
Identifique possíveis erros neste código.
Simplifique este JavaScript para que eu consiga compreendê-lo.


Etapa 3 — Analise o código produzido pela IA
A IA pode produzir código incorreto.
Portanto, você deverá:
executar o código;
verificar se funciona;
identificar erros;
solicitar explicações à IA;
realizar alterações;
testar novamente.
Você é responsável pelo código entregue.
A IA funciona como ferramenta de apoio, mas a decisão sobre o código utilizado deve ser sua.

Etapa 4 — Personalização obrigatória
O site não poderá permanecer simplesmente como a primeira versão produzida pela IA.
Realize pelo menos cinco modificações ou personalizações.
Exemplos:
alterar cores;
alterar fontes;
reorganizar o layout;
trocar imagens;
modificar textos;
criar novos cards;
alterar menu;
melhorar CSS;
modificar JavaScript;
adicionar uma nova funcionalidade.


Etapa 5 — Criar o repositório no GitHub
Crie um repositório no GitHub para armazenar seu projeto.
Sugestão de nome:

Envie para o repositório pelo menos:

style.css
script.js

Caso utilize imagens ou outros arquivos, mantenha-os organizados no projeto.

Etapa 6 — Publicar utilizando GitHub Pages
Utilize o GitHub Pages para publicar seu projeto.
Ao final da publicação, seu site deverá possuir um endereço público semelhante a:
https://seuusuario.github.io/meu-portfolio/

Abra o endereço publicado e verifique se:
a página carrega corretamente;
o CSS está funcionando;
o JavaScript está funcionando;
imagens aparecem;
links estão funcionando;
o site pode ser aberto em outro navegador.


Etapa 7 — Teste final
Antes da entrega, realize os seguintes testes:

O HTML está estruturado corretamente.
O CSS está carregando.
O JavaScript funciona.
O menu funciona.
Os links funcionam.
As imagens aparecem corretamente.
O site apresenta boa visualização no computador.
O site apresenta boa visualização no celular.
Não existem informações pessoais sensíveis.
O conteúdo foi revisado pelo estudante.
O uso de IA foi declarado.

Regra importante sobre Inteligência Artificial
Nesta atividade, utilizar IA é permitido e faz parte do desafio.
Entretanto, utilizar IA não significa simplesmente copiar uma resposta.
O estudante deverá demonstrar:
PROMPT → GERAÇÃO → ANÁLISE → TESTE → ERRO → CORREÇÃO → PERSONALIZAÇÃO → PUBLICAÇÃO
A autoria final do trabalho continua sendo do estudante.
O uso da IA deverá ser declarado, e nenhum dado pessoal, acadêmico ou sensível de terceiros deverá ser fornecido desnecessariamente às ferramentas de IA.
